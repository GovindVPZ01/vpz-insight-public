# VPZ Insight

Static stakeholder dashboard prototype, published using GitHub Pages. The data is a fixed real Mainline snapshot for 12–18 October 2026 and does not automatically refresh. The sign-in screen is a demonstration and provides no access control; do not enter real credentials. This repository and its data are public.

The dashboard includes KPI drill-down and forecast tables from Mainline to sales area, cluster and store. KPI comparisons use transaction-weighted shares; forecast gaps are based on the supplied snapshot forecasts.
